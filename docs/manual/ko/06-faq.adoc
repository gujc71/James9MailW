[[로그인-계정]]
== 로그인 · 계정

**Q. 비밀번호를 잊어버렸습니다.**
관리자에게 비밀번호 재설정을 요청하세요. 관리자가 새 비밀번호를 정해 주면 로그인한 뒤 xref:05-settings.adoc#비밀번호-변경[개인 정보 관리]에서 바꾸세요.

**Q. 로그인이 잠시 안 된다고 나옵니다.**
비밀번호를 여러 번 틀리면 잠시 로그인이 막힙니다. 몇 분 뒤 다시 시도하세요.

**Q. 갑자기 로그아웃되었습니다.**

* 다른 곳에서 비밀번호를 바꾸면 나머지 로그인이 모두 끊어집니다.
* 일정 시간이 지나면 로그인이 만료됩니다. 다시 로그인하세요.
* 관리자가 계정을 중지했을 수 있습니다.

**Q. 화면이 영어로 나옵니다.**
로그아웃한 뒤 로그인 화면에서 **한글**을 고르고 다시 로그인하세요.

[[메일-받기]]
== 메일 받기

**Q. 새 메일이 바로 보이지 않습니다.**
웹메일은 30초마다 새 메일을 확인합니다. 바로 보려면 편지함을 다시 누르거나 F5 로 새로 고치세요.

**Q. 새 메일 알림이 오지 않습니다.**

* 상단 🔔 가 켜져 있는지 확인하세요.
* 브라우저가 알림을 막고 있으면 주소창 왼쪽 자물쇠 아이콘에서 알림을 **허용**으로 바꾸세요.
* 웹메일 창을 보고 있을 때는 알림이 뜨지 않습니다.
* 보낸 · 임시 · 지운 · 스팸 편지함에 들어간 메일은 알리지 않습니다. xref:05-settings.adoc#_55-자동분류[자동분류]로 다른 편지함에 들어간 메일은 알립니다.

**Q. 메일의 그림이 보이지 않습니다.**
추적을 막으려고 외부 그림을 차단합니다. 믿을 수 있는 메일이면 **이미지 표시**를 누르세요(xref:02-mail-read.adoc#원격-이미지-차단[2.6]).

**Q. 받아야 할 메일이 스팸 편지함에 있습니다.**
메일을 열고 **스팸 해제**를 누르면 받은 편지함으로 돌아오고 수신거부에서 빠집니다.

**Q. 특정 사람의 메일이 오지 않습니다.**
xref:05-settings.adoc#_57-수신거부[수신거부] · xref:05-settings.adoc#_55-자동분류[자동분류] · xref:05-settings.adoc#_58-포워딩[포워딩](사본 보관 꺼짐) 규칙에 걸렸는지 확인하세요.

[[메일-보내기]]
== 메일 보내기

**Q. 첨부파일이 너무 크다고 나옵니다.**
일반 첨부는 기본 합계 30MB · 10개까지입니다. 첨부 옆 **전환**이나 **대용량 첨부로 일괄 전환**으로 대용량 첨부로 바꾸세요. 대용량 첨부는 30일 동안만 내려받을 수 있습니다.

**Q. 쓰던 메일이 사라졌습니다.**
같은 브라우저에서 **✎** 로 새 메일을 열면 "…에 쓰던 내용이 남아 있습니다" 가 나옵니다. **이어서 작성**을 누르세요. 첨부파일은 복원되지 않습니다(xref:03-mail-compose.adoc#_38-자동-저장과-이어-쓰기[3.8]).

**Q. 보낸 메일을 취소하고 싶습니다.**
같은 회사(같은 메일 서버) 사람이 아직 읽지 않았다면 xref:03-mail-compose.adoc#_39-보낸-메일-수신-확인과-회수[수신 확인]에서 **회수**할 수 있습니다. 외부 주소로 보낸 메일은 회수할 수 없습니다.

**Q. 외부로 보낸 메일을 읽었는지 알 수 없습니다.**
외부 받는 사람은 "확인 불가 (외부)" 로 나옵니다. 보낼 때 **수신확인요청**을 체크하면 상대가 허락할 때 회신이 옵니다.

**Q. "시도가 너무 많습니다" 가 나옵니다.**
1분에 60통이 넘게 보내면 잠시 발송이 막힙니다. 안내된 시간이 지난 뒤 다시 보내세요.

[[용량]]
== 용량

**Q. 용량이 가득 찼습니다.**

* 사이드 메뉴 아래 사용량을 확인하세요.
* xref:05-settings.adoc#_54-편지함-관리[편지함 관리]에서 편지함별 용량을 보고, 큰 메일을 지운 뒤 **지운 편지함**을 **비우기** 하세요(지운 편지함에 남은 메일도 용량에 포함됩니다).
* 용량을 늘려야 하면 관리자에게 요청하세요.

[[캘린더]]
== 캘린더

**Q. 썬더버드에서 고친 일정이 웹메일에 보이지 않습니다(또는 반대).**
썬더버드는 기본 30분마다 동기화합니다. 썬더버드에서 동기화를 누르거나, 웹메일 캘린더를 새로 고치세요.

**Q. 일정을 고칠 수 없습니다.**
읽기 전용 캘린더(네트워크 구독 캘린더 포함)의 일정은 고칠 수 없습니다.

[[썬더버드-아웃룩]]
== 썬더버드 · 아웃룩

**Q. 메일 프로그램에서 지운 메일이 웹메일에도 없어졌습니다.**
웹메일과 메일 프로그램은 같은 메일함을 봅니다. 한쪽에서 지우면 다른 쪽에서도 지워집니다.

**Q. 비밀번호를 바꾼 뒤 메일 프로그램에서 메일이 안 받아집니다.**
메일 프로그램(그리고 CalDAV · CardDAV 를 연결한 프로그램)에 저장된 비밀번호도 새 비밀번호로 바꾸세요.

**Q. 메일 프로그램 서버 설정 값을 모릅니다.**
IMAP · SMTP 서버 주소와 포트는 관리자에게 문의하세요. 캘린더 · 주소록 연결 정보는 웹메일의 xref:04-calendar.adoc#외부-프로그램과-일정-연결-caldav[CalDAV 안내] · xref:05-settings.adoc#외부-프로그램과-주소록-연결-carddav[CardDAV 안내] 창에서 복사할 수 있습니다.
